配置高德开放平台 Key

本应用使用高德地图「地理编码 + 周边搜索」服务，需要你自己的免费 Key（保存在本地浏览器，不会上传）。

获取步骤：
1. 打开 高德开放平台控制台（需注册，个人免费）
2. 「应用管理」→ 创建新应用 → 添加 Key
3. 服务平台选择 Web端(JS API)
4. 复制 Key 和配套的安全密钥 securityJsCode 填入上方
